## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Saviour13-droid/website-recreations.git
   ```

2. Open the repository folder.
3. Navigate to the category of your choice.
4. Open the desired HTML file in a web browser.

## Cybersecurity & Responsible Use

Cybersecurity demonstrations are intended strictly for educational purposes.

- Test only systems you own or have permission to assess.
- Use synthetic credentials in phishing-awareness simulations.
- Never collect or transmit real passwords.
- Do not use these projects for fraud, impersonation or unauthorized access.
