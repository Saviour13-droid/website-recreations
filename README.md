## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Saviour13-droid/website-recreations.git
```

### 2. Open the project

```bash
cd website-recreations
```

### 3. Explore the projects

Navigate to any category folder:

- `social-media/`
- `ecommerce/`
- `productivity-ai/`
- `cybersecurity/`

Open the desired HTML file in your browser.
